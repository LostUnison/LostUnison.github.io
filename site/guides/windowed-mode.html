    WotLK Warmane Icecrown - Windowed Mode

    Guide by Lost Unison · Last updated 2026-11-19

    Play the 3.3.5a client in a window with one line in Config.wtf.

    Windowed Mode

    • Open your game folder

    • Open config.wtf file inside WTF folder with a text editor

    • Add SET gxWindow "1" in a new line

    • Save and relaunch the game

    Sources: https://forum.warmane.com/showthread.php?t=403829

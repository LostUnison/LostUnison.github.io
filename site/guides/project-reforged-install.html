    What it is

    Project Reforged is a modular HD visual overhaul for the 3.3.5 client. This guide has two parts: first download everything, then install it.

    Part 1: Download everything

    Download all the files first. Put them in one new folder on your desktop. Do not open them yet.

    Each item has a file name button: it downloads the file directly. A Source page link opens the project page only.

    Required

    • St0ny's AIO WoW EXE Patcher (ZIP): open the latest release page and download the ZIP named St0nys-AIO-WoW-EXE-Patcher-<version>.zip (under Assets). The file name has the version number, so this link cannot point to the file directly.

    • Project Reforged Preset: patcher_selection.ini Source page This is the official patch selection of the project. The "Download Preset" button of the Dependencies block gives the same file. It can differ from the preset inside the patcher: in the version we compared, the built-in preset also turned on the patch that stops the random look in character creation.

    Recommended

    • DXVK (modded for WoW), 32-bit: DXVK-WoW-x86.zip Source page Do not download the x64 file: the 3.3.5a client is 32-bit.

    • LuxVelum (fog, light shafts, haze): Luxvelum-Win32.zip Source page This is the only LuxVelum file you need. The ZIP already contains the settings file. St0ny's patcher loads the DLL, so you do not need Luxvelum-version-dll-Win32.zip.

    • Lexara (HD fonts, no addon): lexara.dll and skia.dll Source page St0ny's patch No. 30 loads Lexara.dll. The file lexara.dll is the same file as dinput8.dll (same SHA256), so do not download dinput8.dll.

    • Lights shader (needed by the patch "More lights", No. 68): patch-5.MPQ.zip Source page

    Patch files

    Download only the patches you want. All links are direct. Total size of all 12 patches: about 20 GB.

    • Patch-A Player Characters and NPCs (HD models): core. patch-A.mpq

    • Patch-C Creatures: core. Needs Patch-A. patch-C.mpq

    • Patch-B, Patch-D and Patch-E: one large set. Download all three, or none. Buildings patch-B.mpq, Doodads patch-D.mpq, Environment patch-E.mpq

    • Patch-G Gear and Weapons: core. patch-G.mpq

    • Patch-I Interface: core. patch-I.mpq

    • Optional: Patch-M Maps and Loading Screens patch-M.mpq, Patch-N Darker Nights patch-N.mpq, Patch-P Spell Particle Effects patch-P.mpq

    • Optional: Patch-U Upright Orcs. Needs Patch-A and Patch-C. patch-U.mpq

    • Optional: Patch-S Sounds and Music. Standard (needs Patch-M) patch-S.mpq or Standalone patch-S.mpq (Standalone). Use only one patch-S.mpq.

    Part 2: Installation

    Close the game and the launcher before you start. Make a backup copy of your WoW folder [VERIFY]. Move the mouse over a ? (or click it) to see the details of a line.

    You need an original, unmodified Wow.exe (3.3.5a, build 12340) and Windows PowerShell 5.1 or later (included in Windows 10 and later). The first start checks the file with SHA256.

The patcher shows this selection when you open the patch menu. The file also sets the language to English.

    Step 2: Install DXVK

    • Extract DXVK-WoW-x86.zip. Copy d3d9.dll (32-bit) next to Wow.exe.?You need a graphics card and driver with Vulkan support.Some anti-virus programs flag the 32-bit DLL. Add an exception if the file is removed.To uninstall, delete d3d9.dll from the WoW folder.

    • Make a dxvk.conf file to set the cursor size.?DXVK does not include this file. Make it yourself.1. Open your WoW folder, then the WTF folder.2. Right-click an empty space. Choose New, then Text Document. Name it dxvk.conf. Remove the .txt ending. If you cannot see file endings, turn on File name extensions in the File Explorer View menu.3. Open the file with Notepad. Write this line: d3d9.enlargeHardwareCursor = 1. This gives the original cursor size. The default value is 2.4. Save the file and start the game again.[VERIFY] The folder for this file is not confirmed. If the cursor does not change, move dxvk.conf next to Wow.exe. Standard DXVK reads the file from there.

    • Open the Data folder inside your WoW folder. Copy the Project Reforged patch files into it.?[VERIFY file names and install order].Do not rename the files [VERIFY].

    • Use. In game, press Insert to open the LuxVelum settings window.?The key is set by OverlayKey in WTF\Luxvelum.ini. Ctrl+F7 does not open it. Your changes are saved in WTF\Luxvelum.ini. The log is Logs\Luxvelum.log.LuxVelum selects the fog data with or without the Patch-N darker nights by itself.The release notes say the changes were tested in game on the author's client (RTX 4060, DXVK 3.1.1, Project Reforged patches). The automatic build check did not run Direct3D tests.

    • Copy lexara.dll and skia.dll next to Wow.exe.?Do not copy dinput8.dll too. It is the same file as lexara.dll: the game would load Lexara twice.There is no config file and no addon. HD fonts are always active.If you do not use St0ny's patch No. 30, use dinput8.dll instead of lexara.dll. It contains a folder named patch-5.MPQ, with shader files inside. You must copy this folder into Data.Right-click patch-5.MPQ.zip and choose Extract All. The game then uses Direct3D 9, which is the default.If the file has SET gxApi "opengl", change it to SET gxApi "d3d9".If the file has SET fixedFunction "1", change the value to 0.     Part 3: Check your versions

    Patches and tools change often. This script compares what you have with the official page and with the latest GitHub releases. It does not download or change any patch or tool file.

    • Download the 2 files: check-versions.bat check-versions.ps1

    • Put them in the folder that holds your patch-A.mpq to patch-U.mpq files.

    • Double-click check-versions.bat. On the first run it creates a README.md table in the same folder.

    • Open README.md and write the version you have for each patch and tool. Empty versions show as NOT RECORDED.

    • Run check-versions.bat again. Each line shows OK, UPDATE, MISSING FILE or NOT RECORDED. The script also compares the size of each file with the file on the server.

    • After you update, run check-versions.bat -UpdateReadme to save the new versions in README.md.

    The script needs Windows PowerShell 5.1 or later and an internet connection.

    Show the script (check-versions.ps1) 
    <#
.SYNOPSIS
  Compare the Project Reforged patches in this folder with the official Downloads page.

.DESCRIPTION
  1. Read the versions you have now from the table in README.md (same folder).
  2. Read the current versions from https://projectreforged.github.io/wotlk/downloads/
  3. Show one line per patch: OK, UPDATE, MISSING FILE or NEW ON SITE.
  4. Compare the size of each local .mpq file with the size of the file on the server.
     The patch files are searched in all subfolders (for example the folder "HD patches").
  5. Compare the tools in the "Tools" table of README.md with the latest GitHub release:
     St0ny AIO EXE Patcher, DXVK, LuxVelum, Lexara and the lights shader patch.
  6. Check that the tool files exist in your subfolders (Required, Recommended and so on).
  The script does not download or change any patch or tool file.

.PARAMETER UpdateReadme
  After you updated, write the latest versions (patches and tools) into the README.md tables.

.PARAMETER NoToolCheck
  Skip the check of the tools (St0ny patcher, DXVK, LuxVelum, Lexara, lights shader) on GitHub.

.PARAMETER NoSizeCheck
  Skip the size check (no request to the file server).

.EXAMPLE
  .\check-versions.ps1
  .\check-versions.ps1 -UpdateReadme
#>
param(
    [switch]$UpdateReadme,
    [switch]$NoSizeCheck,
    [switch]$NoToolCheck
)

$ErrorActionPreference = 'Stop'
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12

$Url      = 'https://projectreforged.github.io/wotlk/downloads/'
$Folder   = $PSScriptRoot
if (-not $Folder) { $Folder = Split-Path -Parent $MyInvocation.MyCommand.Path }
$Readme   = Join-Path $Folder 'README.md'

# Index of every file and folder under this folder, subfolders included (one scan).
$All = @(Get-ChildItem -Path $Folder -Recurse -Force -ErrorAction SilentlyContinue)

# Find an item by name in any subfolder. Use 'a|b' for alternative names. -Dir looks for a folder.
function Find-Local([string]$Names, [switch]$Dir) {
    foreach ($n in $Names.Split('|')) {
        $hit = $All | Where-Object { $_.PSIsContainer -eq [bool]$Dir -and $_.Name -ieq $n } | Select-Object -First 1
        if ($hit) { return $hit }
    }
    return $null
}

function Get-RelPath([string]$Full) {
    if ($Full.StartsWith($Folder, [StringComparison]::OrdinalIgnoreCase)) { return $Full.Substring($Folder.Length).TrimStart('\') }
    return $Full
}

function Convert-ToVersion([string]$Text) {
    if ($Text -match '(\d+(?:\.\d+){0,3})') {
        $v = $Matches[1]
        if ($v -notmatch '\.') { $v = $v + '.0' }
        return [version]$v
    }
    return $null
}

function Get-RemoteSize([string]$Link) {
    try {
        $r = Invoke-WebRequest -Uri $Link -Method Head -UseBasicParsing -TimeoutSec 30
        $v = @($r.Headers['Content-Length'])[0]
        if ($v) { return [int64]$v }
    } catch { }
    return $null
}

function Format-Size([int64]$Bytes) {
    if ($Bytes -ge 1GB) { return ('{0:N2} GB' -f ($Bytes / 1GB)) }
    if ($Bytes -ge 1MB) { return ('{0:N1} MB' -f ($Bytes / 1MB)) }
    return ('{0:N0} KB' -f ($Bytes / 1KB))
}

# ---------- 1. Local versions (README.md) ----------
if (-not (Test-Path $Readme)) {
    $template = @'
# Patch HD - Project Reforged (WoW 3.3.5a)

Write the version of each file you have in the Version column. Leave it empty if you do not know.
Run check-versions.bat again after you edit this file.

| File | Content | Version | Type | Size |
|---|---|---|---|---|
| patch-A.mpq | Player characters and NPCs (HD) | | Core | |
| patch-B.mpq | Buildings | | B + D + E set | |
| patch-C.mpq | Creatures | | Core | |
| patch-D.mpq | Doodads | | B + D + E set | |
| patch-E.mpq | Environment | | B + D + E set | |
| patch-G.mpq | Gear and weapons | | Core | |
| patch-I.mpq | Interface | | Core | |
| patch-M.mpq | Maps and loading screens | | Optional | |
| patch-N.mpq | Darker nights | | Optional | |
| patch-P.mpq | Spell particle effects | | Optional | |
| patch-S.mpq | Sounds and music | | Optional | |
| patch-U.mpq | Upright orcs | | Optional | |

## Tools

| Tool | Version | Source |
|---|---|---|
| St0ny AIO EXE Patcher | | https://github.com/Raz0r1337/St0nys-AIO-WoW-EXE-Patcher/releases |
| DXVK | | https://github.com/Raz0r1337/DXVK/releases |
| LuxVelum | | https://github.com/Stormhand-dev/Luxvelum/releases |
| Lexara | | https://github.com/Stormhand-dev/Lexara---HD-Font-Renderer-for-WoW-3.3.5/releases |
| Lights shader | | https://github.com/Raz0r1337/WoW-lights-patch-shader/releases |
'@
    Set-Content -Path $Readme -Value $template -Encoding UTF8
    Write-Host 'README.md was not found. A new README.md was created in this folder.' -ForegroundColor Yellow
    Write-Host 'Open it and write the versions you have. Empty versions show as NOT RECORDED.' -ForegroundColor Yellow
}
$readmeLines = Get-Content -Path $Readme -Encoding UTF8
$local = @{}
foreach ($line in $readmeLines) {
    if ($line -match '^\|\s*patch-([A-Z])\.mpq\s*\|') {
        $cells = $line.Split('|')
        $local[$Matches[1].ToUpper()] = $cells[3].Trim()
    }
}
$localTools = @{}
foreach ($line in $readmeLines) {
    if ($line -match '^\|\s*(St0ny AIO EXE Patcher|DXVK|LuxVelum|Lexara|Lights shader)\s*\|') {
        $cells = $line.Split('|')
        $localTools[$Matches[1]] = $cells[2].Trim()
    }
}
if ($local.Count -eq 0) {
    Write-Host 'No patch rows found in the README.md table.' -ForegroundColor Red
    exit 2
}

# ---------- 2. Site versions ----------
Write-Host "Reading $Url ..."
try {
    $html = (Invoke-WebRequest -Uri $Url -UseBasicParsing -TimeoutSec 30).Content
} catch {
    Write-Host "Cannot read the Downloads page: $($_.Exception.Message)" -ForegroundColor Red
    exit 2
}

$site = [ordered]@{}
foreach ($card in ($html -split 'class="dl-card"')) {
    if ($card -notmatch 'class="dl-patch">Patch-([A-Z])<') { continue }
    $letter = $Matches[1].ToUpper()
    $ver = $null
    if ($card -match 'class="dl-version">.*?v(\d+(?:\.\d+)+)') { $ver = $Matches[1] }
    $links = @([regex]::Matches($card, 'href="([^"]+\.mpq)"') | ForEach-Object { $_.Groups[1].Value })
    $site[$letter] = [pscustomobject]@{ Version = $ver; Links = $links }
}
if ($site.Count -eq 0) {
    Write-Host 'No patch found on the page. The page layout may have changed.' -ForegroundColor Red
    exit 2
}

# ---------- 2b. Tools: latest GitHub release ----------
$tools = @(
    @{ Name = 'St0ny AIO EXE Patcher'; Repo = 'Raz0r1337/St0nys-AIO-WoW-EXE-Patcher' },
    @{ Name = 'DXVK';                  Repo = 'Raz0r1337/DXVK' },
    @{ Name = 'LuxVelum';              Repo = 'Stormhand-dev/Luxvelum' },
    @{ Name = 'Lexara';                Repo = 'Stormhand-dev/Lexara---HD-Font-Renderer-for-WoW-3.3.5' },
    @{ Name = 'Lights shader';         Repo = 'Raz0r1337/WoW-lights-patch-shader' }
)
$toolRows = @()
if (-not $NoToolCheck) {
    foreach ($tl in $tools) {
        $latest = $null; $link = $null
        try {
            $rel = Invoke-RestMethod -Uri ("https://api.github.com/repos/{0}/releases/latest" -f $tl.Repo) -Headers @{ 'User-Agent' = 'check-versions' } -TimeoutSec 30
            $latest = ([string]$rel.tag_name).TrimStart('v', 'V')
            $link = $rel.html_url
        } catch { }
        $have = $localTools[$tl.Name]
        if (-not $latest) { $st = 'CHECK FAILED'; $col = 'Yellow' }
        elseif (-not $have) { $st = 'NOT RECORDED'; $col = 'Yellow' }
        else {
            $a = Convert-ToVersion $have
            $b = Convert-ToVersion $latest
            if (-not $a -or -not $b) { $st = 'CHECK MANUALLY'; $col = 'Yellow' }
            elseif ($b -gt $a) { $st = 'UPDATE'; $col = 'Red' }
            else { $st = 'OK'; $col = 'Green' }
        }
        $toolRows += [pscustomobject]@{
            Tool = $tl.Name; Local = $(if ($have) { $have } else { '-' }); Latest = $(if ($latest) { $latest } else { '-' })
            Status = $st; Link = $link; Color = $col
        }
    }
}

# ---------- 3. Compare ----------
$rows = @()
$letters = @($local.Keys) + @($site.Keys) | Sort-Object -Unique
foreach ($l in $letters) {
    $found = Find-Local ("patch-$l.mpq")
    $file  = if ($found) { $found.FullName } else { $null }
    $have  = [bool]$found
    $lv    = $local[$l]
    $sv    = if ($site.Contains($l)) { $site[$l].Version } else { $null }

    if (-not $site.Contains($l)) { $status = 'NOT ON SITE'; $color = 'Yellow' }
    elseif (-not $have -and -not $lv) { $status = 'NEW ON SITE'; $color = 'Cyan' }
    elseif (-not $have) { $status = 'MISSING FILE'; $color = 'Red' }
    elseif (-not $lv) { $status = 'NOT RECORDED'; $color = 'Yellow' }
    else {
        $a = Convert-ToVersion $lv
        $b = Convert-ToVersion $sv
        if (-not $a -or -not $b) { $status = 'CHECK MANUALLY'; $color = 'Yellow' }
        elseif ($b -gt $a) { $status = 'UPDATE'; $color = 'Red' }
        elseif ($b -lt $a) { $status = 'LOCAL IS NEWER'; $color = 'Yellow' }
        else { $status = 'OK'; $color = 'Green' }
    }

    $sizeNote = ''
    if ($have -and -not $NoSizeCheck -and $site.Contains($l) -and $site[$l].Links.Count -gt 0) {
        $localSize = (Get-Item $file).Length
        $matched = $null
        $known = $false
        foreach ($lk in $site[$l].Links) {
            $rs = Get-RemoteSize $lk
            if ($null -eq $rs) { continue }
            $known = $true
            if ($rs -eq $localSize) {
                $matched = if ($lk -match '/extras/') { 'same size as the extras file' } else { 'same size as the main file' }
                break
            }
        }
        if ($matched) { $sizeNote = $matched }
        elseif ($known) {
            $sizeNote = 'size differs from the server'
            if ($status -eq 'OK') { $status = 'OK (size differs)'; $color = 'Yellow' }
        }
        else { $sizeNote = 'size not checked' }
    }

    $rows += [pscustomobject]@{
        Patch = "patch-$l"; Local = $(if ($lv) { $lv } else { '-' }); Site = $(if ($sv) { $sv } else { '-' })
        Status = $status; Size = $sizeNote; Color = $color
    }
}

# ---------- 4. Report ----------
Write-Host ''
Write-Host ('{0,-10} {1,-10} {2,-10} {3,-18} {4}' -f 'Patch', 'You have', 'Site', 'Status', 'File size')
Write-Host ('-' * 78)
foreach ($r in $rows) {
    Write-Host ('{0,-10} {1,-10} {2,-10} {3,-18} {4}' -f $r.Patch, $r.Local, $r.Site, $r.Status, $r.Size) -ForegroundColor $r.Color
}

if ($toolRows.Count -gt 0) {
    Write-Host ''
    Write-Host ('{0,-24} {1,-12} {2,-12} {3}' -f 'Tool', 'You have', 'Latest', 'Status')
    Write-Host ('-' * 78)
    foreach ($r in $toolRows) {
        Write-Host ('{0,-24} {1,-12} {2,-12} {3}' -f $r.Tool, $r.Local, $r.Latest, $r.Status) -ForegroundColor $r.Color
        if ($r.Status -in @('UPDATE', 'NOT RECORDED') -and $r.Link) { Write-Host ('{0,-24} {1}' -f '', $r.Link) }
    }
}

# ---------- 4b. Tool files in your folders ----------
$expected = @(

    Troubleshooting

    • Nothing changes: check that the patch files are in Data and that the EXE patcher was applied.

    • The game does not start: remove the DLL files you added one by one (LuxVelum, Lexara, then DXVK). Start with the last one you installed.

    • Delete the Cache folder again and relaunch.
